📊 Guia Rápido do Dashboard

Sistema de Análise de Dados de Obesidade

🚀 Início Rápido

1

Instale as Dependências

Abra o terminal/prompt e execute:

pip install -r requirements.txt
2

Prepare os Dados

Certifique-se de que o arquivo Obesity_Tratado.csv está na mesma pasta do script Python.

3

Execute o Dashboard

No terminal, execute:

python dashboard_obesidade_interativo.py
4

Acesse no Navegador

Abra seu navegador e acesse:

http://127.0.0.1:8050/

📖 Como Usar o Dashboard

Filtros no Painel Esquerdo

Use os dropdowns para filtrar os dados:

  • Sexo: Selecione Masculino, Feminino ou Todos
  • Faixa Etária: Filtre por grupos de idade
  • Nível de Obesidade: Foque em categorias específicas
  • Histórico Familiar: Filtre por presença de histórico
💡 Dica: Combine múltiplos filtros para análises mais específicas!

Cards de Estatísticas

No topo da página, 4 cards mostram:

  • Total de Pacientes: Quantos registros correspondem aos filtros
  • IMC Médio: Média do Índice de Massa Corporal
  • Idade Média: Média etária dos pacientes filtrados
  • % Obesidade: Percentual de pacientes com obesidade (tipos I, II, III)

Abas de Visualização

📊 Distribuições: Veja como os dados estão distribuídos

  • Gráfico de barras por nível de obesidade
  • Boxplot de IMC por sexo
  • Histograma de idades
  • Scatter plot de peso vs altura

🔄 Correlações: Identifique relações entre variáveis

  • Matriz de correlação (heatmap)
  • IMC vs atividade física
  • IMC por variáveis categóricas
  • Consumo de água vs IMC

📈 Comparações: Compare grupos e categorias

  • Consumo de vegetais por obesidade
  • Atividade física por categoria
  • Meio de transporte vs obesidade
  • Tecnologia vs IMC

📋 Tabela: Dados detalhados e exportáveis

  • Visualize todos os dados filtrados
  • Ordene por qualquer coluna
  • Filtre valores específicos
  • Exporte para Excel

🖱️ Recursos Interativos dos Gráficos

Ações Disponíveis

  • Hover (passar o mouse): Veja detalhes de cada ponto/barra
  • Clicar e arrastar: Faça zoom em uma região específica
  • Duplo clique: Resete o zoom
  • Clicar na legenda: Oculte/mostre categorias
  • Botões superiores: Zoom in/out, pan, reset

💡 Insights que Você Pode Obter

Análises Demográficas

Identifique padrões de obesidade por:

  • Distribuição etária

Explore relações entre:

  • IMC e atividade física

🎯 Dicas de Uso

⚡ Para análises rápidas: Use os filtros e observe os cards de estatísticas. Eles fornecem um resumo instantâneo.
💡 Para análises profundas: Combine filtros e navegue por todas as abas. Compare diferentes segmentos de pacientes.
⚠️ Atenção: Sempre considere o tamanho da amostra filtrada. Grupos muito pequenos podem não ser estatisticamente significativos.

🔧 Solução de Problemas

Dashboard não inicia

Verifique:

  • Se todas as bibliotecas foram instaladas corretamente
  • Se o arquivo CSV está no mesmo diretório
  • Se a porta 8050 está disponível

Gráficos não aparecem

Soluções:

  • Atualize a página (F5)
  • Limpe o cache do navegador
  • Tente outro navegador (Chrome recomendado)

Erro ao exportar dados

Certifique-se de que:

  • Há dados filtrados na tabela
  • Você tem permissão para salvar arquivos no seu computador
